# 用量估计（Usage Cost for DeepSeek Harness）

在 DSH 里直接看见「这句话花了多少钱」。

每条回答的操作行里会多出一个估算金额（`≈¥0.021 · 12.4K tokens`），左侧栏还提供一个用量面板：单轮明细、今日/本月/本年汇总、账户余额、月度预算与 CSV 导出。

金额按 DeepSeek 官方 API 单价与**服务商实际上报的 token** 计算，不发起任何额外模型请求。

> 已在 DeepSeek Harness 桌面端 `0.2.2-rc.5`（macOS）验证。

---

## 功能

| 位置 | 内容 |
|---|---|
| 每条回答的操作行 | `≈¥0.021 · 12.4K tokens`：本轮估算金额 + 本轮 token，点击打开面板 |
| 左侧栏「用量估计」 | 汇总区（合计金额 / 合计 tokens / 轮次 / 账户余额）+ 明细表 |
| 面板明细表 | 时间、提问摘要、模型、未命中输入、缓存命中、输出、金额、累计；跨会话 |
| 视图 | 今日 / 本月 / 本年 / 全部（按本地日历聚合） |
| 价格表 | 两个模型 × 高峰/空闲 × 命中/未命中/输出，六个数值可改；带节假日清单 |
| 预算 | 月度金额 + 提醒阈值（默认 80%），进度条与超阈值提醒，同月同阈值只提醒一次 |
| 导出 | 当前视图导出 CSV（含合计行） |
| 余额 | 读取当前登录账号的钱包（人民币优先，含赠送） |

示例（面板明细）：

```
时间          提问                      模型              未命中   缓存命中   输出     金额
11-23 16:22   帮我看看这个并发问题        deepseek-flash     1,421   288,512   2,149   ¥0.0233
11-23 16:08   这段 SQL 为什么慢           deepseek-flash       962    60,128   1,344   ¥0.0081
```

## 安装

1. 克隆或下载本仓库到任意目录：

   ```bash
   git clone https://github.com/kll-92/dsh-usage-cost.git
   ```

2. 打开 DSH → 设置 → 插件 → 添加插件 → 选择这个目录。
3. 启用后，左侧栏出现「用量估计」。

DSH 以**链接**方式安装本地目录，所以更新代码后需要在插件列表里**禁用再启用**该插件，页面才会加载新的浏览器产物（插件会请求 DSH 重新读取自己的产物；若仍不生效，重启 App）。

## 使用

- **看单轮金额**：任意一条回答结束，操作行里出现 `≈¥…`。鼠标悬停会说明当前状态（已定价 / 未定价 / 无数据 / 还没读到）。
- **看总账**：点左侧栏「用量估计」，切换 今日/本月/本年/全部。
- **改价**：面板 →「价格表」。服务商调价后在这里改，历史金额按新价重算（账本只存 token，不存钱）。
- **设预算**：面板 →「预算」，填月度金额与阈值。
- **导出**：面板 →「导出 CSV」。

## 计费口径

金额 = Σ(token × 对应单价) ÷ 1,000,000，币种人民币。

| 模型 | 输入·缓存命中（空闲/高峰） | 输入·未命中（空闲/高峰） | 输出（空闲/高峰） |
|---|---|---|---|
| `deepseek-flash` | ¥0.02 / ¥0.04 | ¥1 / ¥2 | ¥4 / ¥8 |
| `deepseek-v4-pro` | ¥0.15 / ¥0.30 | ¥4.5 / ¥9 | ¥13.5 / ¥27 |

单位：元 / 百万 tokens。来源：DeepSeek 官方定价页（2026-11 版）。

- **高峰时段**：北京时间周一至周五 9:00–12:00、14:00–18:00（不含中国法定节假日）；其余时间（含周末、节假日）为空闲时段，单价减半。
- 一轮对话按**轮结束时间**判定时段；跨时段的轮次有微小误差。
- **缓存写** token 计入「未命中」；**推理** token 包含在「输出」里，不单独计价。
- 价格表里没有的模型显示「未定价」，不计入合计；没有服务商上报的轮次显示「无数据」，不做估算。

> 这是估算，不是官方账单。官方调价后请更新价格表；默认价随插件版本更新。

## 隐私与安全

- **只读**：只读取本机会话记录（`ctx.remote.session`），不发起模型请求，不写入会话日志。
- 账本（每轮 token）存在浏览器 `localStorage`（键 `dsh.usage-cost.v1`），只在这台电脑的这个浏览器里。
- 余额来自你已登录的 DeepSeek 账号接口，不额外保存凭证。
- 关闭插件后入口与行内金额消失，账本保留在本地；重新启用后继续使用。

## 已知限制

- 面板的**模型/工作区筛选**、子任务开关尚未接上（子任务行已按会话 `origin` 标注，默认计入合计）。
- 余额依赖 DSH 暴露账户接口；未登录或接口缺失时显示「不可用」，不影响其它数字。
- 只在 macOS 桌面端 `0.2.2-rc.5` 验证过；接口变化可能需要跟进。
- 账本受浏览器存储配额限制，超出时保留最新一半。

## 开发

```
src/core.cjs       纯计价核心（峰谷、三桶、聚合、格式化、CSV），不碰 DOM
src/ui.js          账本、面板、行内金额
src/register.js    槽位注册（左侧栏 / 主面板 / 回答操作行）
index.js           Host 半边（只为让包成为可用 Loader 条目，并请求刷新浏览器产物）
client.js          构建产物（由上面三个文件拼接，勿手改）
tests/             node:test 用例（38 条），含真实会话夹具
```

```bash
node --test tests/*.test.cjs   # 运行测试
node scripts/build.mjs         # 重新生成 client.js
```

`client.js` 是给 DSH 直接加载的单文件脚本；`src/` 才是源码。改了 `src/` 必须重新构建。
