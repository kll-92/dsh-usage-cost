# 用量估计（Usage cost）

在 DSH 里估算每一轮对话花了多少钱。

## 它做什么

- 左侧栏新增「用量估计」入口，点开是主栏面板。
- 每条完成回答的**操作行里**（和「用量 N tok」同一行）显示 `≈¥0.021 · 12.4K tokens`（估算金额 + 这一轮的总 token），点击可打开面板并定位到该轮。
- 面板顶部显示**账户余额**（充值 + 赠送，人民币优先），打开面板或点「刷新」时重新读取
- 面板按 今日 / 本月 / 本年 / 全部 汇总，表格里每轮一行：时间、提问摘要、模型、未命中输入、缓存命中、输出、金额。
- 金额来自服务商每轮上报的真实 token，乘以内置价目表。

## 口径

- 价格：人民币 / 百万 tokens，`deepseek-flash` 与 `deepseek-v4-pro`，分高峰与空闲两档；高峰为北京时间周一至周五 9:00–12:00、14:00–18:00（不含法定节假日）。
- 缓存写 token 计入缓存未命中；推理 token 含在输出里，不单独计价。
- 估算，不是账单：官方调价后需要更新价目表。

## 数据与隐私

- 只读本机会话记录，通过 DSH 既有的会话接口读取；不发起模型请求，不写会话日志。
- 账本（轮次金额的原始 token）存在浏览器本地存储，仅这台电脑的这个浏览器可见。
- 关闭插件后入口与行内金额消失，账本仍留在本地；重新启用后继续使用。

## 已知限制

- **改了 `client.js` 之后，刷新页面不够**：DSH 在启动时把每个插件的浏览器产物读进内存。本插件的 Host 半会主动调用 `clientModules.rebuilt`，所以在「插件」里禁用再启用插件即可让页面加载新产物；若那次调用失败，才需要重启 App。
- 面板里的模型/工作区筛选、子任务开关尚未接上（行内金额与日/月/年汇总已可用）。
- 第一次打开面板需要回填历史会话，会话多时会显示进度。
- 行内金额只对账本里已有的轮次生效；账本里还没有这一轮时先显示 `¥…`，读到后自动更新（最多重试一次）。
- 高峰/空闲按轮结束时间判定，跨时段的轮次有微小误差。
- 「定位到该轮」只到"能看见"的程度：点击行内金额后面板会高亮那一行并把视图切到「全部」，不会滚动页面——插件不碰 DOM。
- DSH 升级后若接口或槽位改名，面板会在诊断行下方给出「运行在 DSH x，本插件验证于 y」的提示，而不是白屏。
